# Это монорепа проекта svoi-film для проекта по микросервисам

## Что нужно установить, чтобы работало:

### Если винда, то нужен [scoop](https://scoop.sh/#/)

Scoop это пакетный менеджер для винды, из которого можно удобно установить большую часть
программ для программирования, пользуйтесь.

```pwsh
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

### Make

Make используется, чтобы сократить длинные скрипты, которые описаны в Makefile

Windows

```bash
scoop bucket add main
scoop install main/make
```

MacOS

```bash
brew install make
```

## Как запустить

По скольку для запуска всего проекта целиком надо запустить че-то типа 30 контейнеров – 8 мксов для каждого апи, база, воркер и аутбокс – есть вариант частичного запуска для одного микросервиса.

### Локальная разработка одного микросервиса

Переходим в папку микросервиса и запускаем команду

```bash
make docker-infra # Поднимает инфру (базу, аутбокс и реббит) в докере
make api # запускает API микросервиса локально
make worker # Запускает Worker локально
```

После этого:

- Postgres – localhot:5432
- RabbitMQ – localhost:5672,
- RabbitMQ UI – http://localhost:15672

### Запуск всего проекта целиком

В этой папке запускаем. Это дело поднимет все микросервисы и инфру для них в докере

```bash
make up
```

## Как устроена инфра

Все запускается в docker-compose

Глобальная инфра находится в файла `compose.infra.yaml`. У нас из глобального rabbitmq и виртуальная сеть для сервисов (по-умолчанию контейнеры в докер друг друга не видят).

Дальше у каждого сервиса есть свой `compose.yaml` файл в папке с сервисом, обычно он устроен так:

- API сервиса – FastAPI приложение
- Worker сервиса – Подписывается на топики RabbitMQ. Faststream приложение. Из-за особенностей питона нельзя в один сервис их посадить.
- Outbox сервиса – перекладывалка из базы в реббит. сделал отдельным сервисом, чтобы везде был одинаковый.
- Внутренний Postgres для сервиса.
